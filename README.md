# JavaScript Projects

This repository documents the projects completed during my front-end development course. The coursework covers semantic HTML, responsive CSS, Bootstrap layout, and JavaScript interactions.

## Course Projects

### Personal Portfolio Website

A responsive, one-page portfolio built with HTML, CSS, and JavaScript. It introduces my work and includes About, Projects, Gallery, Skills, and Contact sections. The image gallery opens a lightbox with captions, previous and next controls, keyboard navigation, and close behavior.

### Simple Recipes Landing Page

A recipe-themed landing page with a hero section, navigation, imagery, and responsive styling.

### About Section

An informational section presenting a personal introduction with structured content and anchor navigation.

### Contact Section and Form

A contact area combining contact details with a labeled form and a responsive layout.

### Bootstrap Footer

A responsive multi-column footer built with Bootstrap grid classes for contact information, social links, and copyright details.

## Skills Practiced

- Semantic HTML and accessible page structure
- CSS styling, responsive layouts, and visual design
- Bootstrap grid utilities
- JavaScript-driven gallery interactions
- Git and GitHub workflow
